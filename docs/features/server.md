# server

> **Renamed.** The `idx server` command has been renamed to `idx agent`. The `server` name is retained as a backward-compatible alias.

See [agent.md](agent.md) for full documentation.

## Migration

| Old command | New equivalent |
| --- | --- |
| `idx server start` | `idx agent start` |
| `idx server stop` | `idx agent stop` |
| `idx server status` | `idx agent status` |
| `idx server status --json` | `idx agent status --json` |
